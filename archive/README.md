# Archive: Non-Reportable and Deprecated Scripts

This directory contains deprecated, exploratory, and non-reportable scripts from prior iterations of the project.

## Non-Reportability Notice
As established in the formal project review ("TrustRisk-WDS: Proposal vs. Implementation Review and Roadmap to a Publishable Paper", Section 6, Phase 0):
- **All outputs generated by scripts in this directory are non-reportable and invalid for publication.**
- Scripts in this directory contain post-hoc manipulations, label-informed optimizations, threshold sweeps on test labels, or oracle probability injections.
- They are preserved solely for historical auditability and must NEVER be imported or executed in the production, evaluation, or manuscript pipelines.

## Contents
- `train_oracle.py`: Oracle detector using ground-truth labels.
- `improve_detection.py`, `restore_real.py`: Multipliers and EMA post-hoc transforms applied to pipeline probabilities.
- `train_fused.py`, `train_rf_booster.py`: Heuristic booster scripts overwriting trust pipeline data.
- `patch_dashboard.py`, `patch_modes.py`, `patch_risk.py`: Self-patching scripts.
- `update_dashboard.py`: Dashboard overrides.
- `get_pw.py`, `get_pw2.py`: Scripts sweeping thresholds directly on test labels.
- `integrate_clean_zone_model.py`, `compare_systems_val_test.py`, `evaluate_both_systems.py`: Exploratory zone testing scripts.
- `debug_shap.py`, `evaluate_virgin.py`, `phase5_investigation.py`: Temporary diagnostic scratch scripts.
- `legacy_reports/`: Deprecated reports (`PROJECT_REPORT.md`, `final_evaluation_metrics.json`) from the pre-freeze GNN-GRU attempt.
- `legacy_preprocessing/`: Deprecated `build_dataset_legacy.py` that mapped unlabelled `-999` rows to `0`.
